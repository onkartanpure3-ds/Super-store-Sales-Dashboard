# 🛒 Super Store Sales Dashboard --- Power BI

An interactive **Super Store Sales Dashboard** built using **Microsoft
Power BI** to explore sales performance across customer segments,
product categories, payment methods, shipping modes, and regions.

The dashboard brings key sales information into one visual report,
making it easier to compare business segments, identify high-volume
categories, and explore sales and profit trends over time.

------------------------------------------------------------------------

## 📊 Project Overview

The Super Store Sales Dashboard provides a consolidated view of store
performance through interactive charts and a regional filter.

Users can explore: - How sales are distributed across customer
segments. - Sales trends over order dates. - The number of sales across
product categories and sub-categories. - The distribution of sales by
payment mode. - The number of sales handled by different shipping
modes. - Regional performance using the Region slicer.

------------------------------------------------------------------------

## 🎯 Dashboard Features

### 1. Region Filter

-   Interactive slicer for **Central, East, South, and West**.
-   Select a region to filter the dashboard visuals.

### 2. Sales by Customer Segment

-   Donut chart showing the share of sales across Consumer, Corporate,
    and Home Office segments.
-   Helps compare the contribution of each customer segment.

### 3. Sales Trend by Order Date

-   Area/line chart showing the sales trend across order dates.
-   Supports exploration of changes in sales volume over time.

### 4. Sales by Category

-   Bar chart comparing sales counts across:
    -   Office Supplies
    -   Furniture
    -   Technology

### 5. Sales by Payment Mode

-   Donut chart showing the distribution of sales across:
    -   COD
    -   Online
    -   Cards

### 6. Profit Trend by Order Date

-   Area/line chart showing the profit trend across order dates.
-   Helps review how profit changes over the displayed period.

### 7. Sales by Sub-Category

-   Bar chart highlighting selected sub-categories, including:
    -   Bookcases
    -   Machines
    -   Copiers

### 8. Sales by Ship Mode

-   Bar chart comparing the displayed shipping modes:
    -   Standard Class
    -   First Class
    -   Second Class
    -   Same Day

## 🚀 How to Use

1.  Clone or download this repository.
2.  Open `Super-Store-Sales-Dashboard.pbix` in **Power BI Desktop**.
3.  If Power BI asks for the source data, connect the dataset used in
    the project.
4.  Refresh the report if the source data has changed.
5.  Use the **Region** slicer to explore the dashboard for Central,
    East, South, or West.
6.  Select chart elements to interact with the report and compare the
    displayed results.

------------------------------------------------------------------------

## 💡 Project Purpose

This project demonstrates how a business dashboard can turn sales data
into an interactive visual report. It provides a simple way to explore
customer segments, product categories, payment preferences, shipping
modes, and time-based sales and profit patterns.
